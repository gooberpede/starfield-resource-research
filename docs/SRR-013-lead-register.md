# SRR-013 implementation leads

| Lead | Disposition | Evidence or next gate |
| --- | --- | --- |
| Published context and a readable owner decoy | Resolved for the disposable layout | Require the published pointer, the exact embedded address and owner vptr, then validate the PerBiomeData receiver and registered descriptor. The fixture includes a byte-copied owner with the correct vptr and a foreign publication address. |
| Direct block, leaf directory and internal descent | Resolved for the documented shape | Exercise the same decoder with a direct packed block, a multi-block leaf, and two depths of internal nodes. The range walk checks successor coverage against the root and inspects a duplicate across leaves. |
| Local directory and malformed-pointer checks | Resolved for exercised shapes | Malformed descriptors, counts, spans, alignment and access protection cause refusal. A safety limit is incomplete coverage. |
| False minimum beyond a reached upper fence | Resolved by independent counterexample and regression | A trailing block in a visited leaf hid a duplicate Frozen edge despite apparently sorted minima. Probe every block's first descriptor and key in the visited leaf. Entirely unvisited subtrees remain outside the bounded observation. |
| Rebased PE header and late identity read | Resolved in disposable admission | The Windows loader rebases `ImageBase`. Verify that field against the actual module base when rebased, alongside the unchanged header bytes and code windows. Check the monotonic deadline again after the final identity operation. |
| Runtime form substitution and effective inputs | Resolved for the disposable profile. Blocked for actual effective-input admission | The typed map, PNDT seed and key, BIOM-side list and PPBD override provide independent runtime joins. A future retail measurement needs an attributable load order and independently qualified work set, BIOM lists, RSGD, IRES and ATMO inputs. |
| Root, path or payload mutation between collections | Resolved for observable disagreements | Refuse the measurement when evidence disagrees. An ABA restore and a stable intermediate clear can give agreeing pairs. A stronger guarantee would require a proven native synchronization boundary or another acquisition method supported by evidence. |
| Reading other native state to infer execution or persistence | Excluded | Read only the selected retained payloads and required identity and range witnesses. Lifecycle and save questions require independent evidence. |
| Actual title, menu and gameplay access and mapping attribution | Blocked for retail | The executable pin limits future applicability to 1.16.244.0. Retail path, Steam and session attribution, OS access, focused mapped-code attestation and checkpoint availability require an approved retail adapter and separate written authorization. |
| Save2 versus Save52 and travel | Excluded from disposable qualification | State-only inspection is independent of travel. Any future authorized travel plan uses Save52 under the separate copy, custody and comparability conditions in the [proposed run card](SRR-013-proposed-title-run-card.md). |
