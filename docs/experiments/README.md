# Experiments and Evidence

These records preserve individual investigations, including hypotheses and
paths that were later marked **SUPERSEDED**. The
[current v1 baseline](../v1-research-baseline.md) governs current conclusions.

The [evidence bundles](evidence/) contain selected, focused Ghidra-derived
artifacts supporting specific findings. They are intentionally bounded rather
than complete executable exports. Raw x64dbg traces, session databases, memory
dumps, and other bulk runtime captures remain local/private unless deliberately
reviewed and transformed into a scoped research artifact.

Use the repository evidence labels—**PROVEN**, **STRONG**, **PROVISIONAL**,
**COUNTERFACTUAL**, and **SUPERSEDED**—when interpreting or extending these
records.
