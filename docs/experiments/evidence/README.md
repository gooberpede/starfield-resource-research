# Focused Evidence Bundles

This directory contains deliberately selected Ghidra-derived evidence that
makes specific reverse-engineering claims inspectable and falsifiable. It is
not a complete executable export and does not contain proprietary binaries,
Ghidra project databases, raw debugger traces, or memory dumps.

Each bundle documents its source identity, scope, and reproduction method.
See [project provenance](../../PROVENANCE.md) and the
[third-party notice](../../../THIRD_PARTY_NOTICES.md) for version and rights
boundaries.
