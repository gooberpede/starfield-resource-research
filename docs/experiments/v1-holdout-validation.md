# v1 Fresh Holdout Validation

## Purpose

Provide independent validation after the recovered inorganic-resource-generation algorithm was considered complete and after the guarded biome-family fallback and Special-before-guards corrections.

This is an output corroboration layer. It does not prove that Creation Kit native addresses equal retail `Starfield.exe` addresses.

## Sample

```text
Vesta — Lunara
Niira — Narion
Eridani IV — Eridani
Cassiopeia IV-a — Eta Cassiopeia
Cassiopeia II-a — Eta Cassiopeia
Zosma V-a — Zosma
Eridani III-b — Eridani
Luyten's Rock — Luyten's Star
Bardeen V-d — Bardeen
Ka'zaal — Nirah
```

## Selection Intent

The sample represents dimensions that had previously exposed or could expose model errors:

- atmosphere/terrestrial overlap;
- Water/Everywhere duplication;
- atmospheric descendant-family members;
- single- versus multi-resource atmosphere;
- capacity, cache, and fallback opportunities.

These bodies were fresh holdouts rather than algorithm-discovery or earlier detailed regression cases.

## Result

For all ten bodies:

```text
reproducer atmospheric resources == observed atmosphere
reproducer biome distributions == Creation Kit
reproducer planet-wide set == retail planetary scan
```

Overall:

```text
10 / 10 exact
0 observed errors
```

No per-biome tables or unrecorded per-body values are inferred in this note.

## Evidence Boundary

The Creation Kit comparison validates biome-local terrestrial assignments. The retail planetary scan validates final planet-wide membership. Their agreement independently corroborates the recovered model, but neither comparison maps CK function addresses into the retail executable.
