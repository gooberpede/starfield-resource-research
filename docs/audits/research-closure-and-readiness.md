# Research closure and readiness

**20 November 2026 · SRR-025 · Recommendation to the maintainer**

**READY — close active research** on the v1.0 inorganic generation model. A downstream developer can reproduce the canonical result, obtain biome-level resource membership from a documented consumer export, and identify exactly where the evidence runs out. These satisfy the agreed standard of a validated, reproducible and documented foundation within the tested scope. No corrective investigation is required for that use. The maintainer owns the closure decision.

A biome containing both resources is a candidate for a site search. The evidence gives no distance between deposits, vein geometry, guarantee of access within an outpost radius or extractor location. Organics, arbitrary plugin orders and unsupported executable builds also fall outside this decision. Historical writer timing would not resolve any of those questions.

## When to reopen

Reopen the affected claim for a reproducible discrepancy on supported inputs, a relevant CK, retail or plugin version change, newly available primary evidence that discriminates between explanations, or a concrete downstream requirement beyond the present scope. Preserve the failing input, build, expected channel and observed result. For a settled rule, reconcile the evidence and baseline before changing the sibling model and rerunning its regressions.

For example, a new same-input retail lane mismatch would challenge the diagnostic result. First check the body/biome key, lane, input identity and comparison projection. A request for the actual startup writer would justify A8, while a need to know which typed inputs survived to sweep entry would justify A9. A Volii visit-timing observer would date a body-keyed mutation. A matched Kreet orbital image could settle the separate display question. None is needed to consume v1.0 membership. A live experiment would need separate authorization.
